Import submittal logLoads tracking-log rows (JSON prepared from the office Excel log) into the projects' Submittals tabs
This tool is for the office (admin / manager / PM roles).

Pick the tracking_rows.json file. Rows that already exist (same project, number and revision) are skipped, so running the same file twice adds nothing. Existing app rows listed under updates get their submitted / returned dates, status and vendor filled in; nothing is deleted.
