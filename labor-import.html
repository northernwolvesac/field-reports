Import a Mason payroll journal

Pick the QuickBooks journal CSV Mason sends after each payroll (Northern_Wolves_QBO_Payroll_JEs_….csv: Journal No., Journal Date, Account Name, Debits, Credits, Description, Name). Only the project lines are read — Labor Cost (W-2), Payroll Taxes (Labor W-2), Labor Cost (1099NEC), Reimbursable Expenses — and the project is the Name column. Payrolls already imported are skipped, so the same file can be loaded twice.
